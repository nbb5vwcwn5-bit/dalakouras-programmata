# Προγράμματα και επιδοτήσεις – dalakouras.gr

Το αρχείο `programmata.json` περιέχει τη λίστα των προγραμμάτων που δείχνει η σελίδα «Επιδοτήσεις» του dalakouras.gr. Το site το διαβάζει αυτόματα μία φορά τη μέρα.

Η λίστα ενημερώνεται αυτόματα δύο φορές την εβδομάδα. Οι κανόνες της ενημέρωσης βρίσκονται στο `UPDATE-RULES.md`.

Οι πληροφορίες είναι περιληπτικές. Για όρους, ποσά και προθεσμίες ισχύει πάντα η επίσημη πρόσκληση κάθε προγράμματος.
